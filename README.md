# WoW_Forever_AddOns

Addons for World of Warcraft: Forever (interface 16001). See [AGENTS.md](AGENTS.md) and [SKILLS.md](SKILLS.md) for how addons here are built and maintained.

## Addons
- [Forever Ground Markers](ForeverGroundMarkers/README.md): persistent location markers, inspired by RuneLite's Ground Markers.
- [Forever Vendor Snipe](ForeverVendorSnipe/README.md): lists Auction House items selling below their vendor price, ranked by profit, plus the items with the biggest gap between their cheapest and second cheapest auction.
